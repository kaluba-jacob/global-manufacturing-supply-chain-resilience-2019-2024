# Global Manufacturing Supply Chain Resilience Analysis (2019–2024)

> Analysis of global manufacturing supply chain restructuring, friend-shoring / near-shoring trends and regionalization of global value chains.

## 📊 Project Overview
- **Topic**: Friend-shoring, near-shoring and regionalization of global manufacturing value chains (2019–2024)
- **Key Questions**:
  1. How has global manufacturing trade flow shifted after 2019?
  2. Which industries have seen increased supply chain regionalization?
  3. How does logistics infrastructure affect supply chain concentration?

## 🛠️ Tech Stack
- **Data Processing & Analysis**: R (tidyverse)
- **Interactive Dashboard**: Power BI
- **Data Sources**: UN Comtrade, OECD TiVA, World Bank LPI

## 📁 Repository Structure
├── R-scripts/          # Data download, cleaning and indicator calculation scripts
├── Power-BI/           # Power BI dashboard file & DAX documentation
├── data/
│   ├── raw/            # Raw source data (not committed, auto-downloadable via scripts)
│   └── processed/      # Cleaned aggregated data for Power BI
└── report/             # Business analysis report


## 📈 Core KPIs
- Import share by region / partner
- Supply chain geographic concentration
- Logistics Performance Index (LPI)
- Upstream concentration ratio

## 🌍 Insights for African Manufacturing
A dedicated section on implications and opportunities for African manufacturing supply chains is included in the final report.

## ⚠️ Limitations
- Data covers 2019–2024
- Country and industry coverage varies by data source
- Analysis based on official trade statistics
